Məxfilik siyasəti

Sürücü: Qaydalar və Testlər · Son yenilənmə: 28 sentyabr 2026

Sürücü: Qaydalar və Testlər (az.surucu.app) yol hərəkəti mövzularını öyrənməyə və demo testlərlə məşq etməyə kömək edən müstəqil Android tətbiqidir. Tərtibatçı: javid.gstudio. Dövlət qurumunun rəsmi tətbiqi deyil. Bu siyasət hazırkı 1.0.0-rc1 test versiyasına aiddir.

Toplanan məlumatlar

Hazırkı 1.0.0-rc1 versiyası hesab yaratmır, reklam göstərmir, üçüncü tərəf analytics və crash SDK-sı istifadə etmir və şəxsi məlumatı avtomatik serverə göndərmir.

Tətbiq aşağıdakı məlumatları yalnız cihazda saxlayır:

  • demo imtahan sessiyaları və cavablar;
  • səhvlər və təkrar cədvəli;
  • favorilər, yol nişanı səhv dəftəri və lokal statistika;
  • istifadəçinin cihazda yazdığı profil adı;
  • tema, bildiriş və səs seçimləri.

Tətbiq gözlənilmədən bağlandıqda yalnız hadisənin vaxtı və xəta sinfinin texniki adı cihazda saxlanılır. Xəta mesajı, stack trace, profil adı, cavablar və öyrənmə tarixçəsi yazılmır. İstifadəçi məxfilik ekranında hesabatı əvvəlcə nəzərdən keçirib Android paylaşım pəncərəsi vasitəsilə könüllü göndərə bilər; avtomatik göndəriş yoxdur.

Saxlanma və silinmə

Məlumatlar Android Room, DataStore və daxili tətbiq yaddaşında saxlanılır. Android backup söndürülüb. İstifadəçi “Profil → Məxfilik və məlumatlar” bölməsindən imtahanları, səhvləri, təkrar cədvəlini, favoriləri, yol nişanı səhv dəftərini, öyrənmə aktivliyini və lokal xəta marker-ini silə bilər. Bu əməliyyat profil adını, tema, bildiriş və səs seçimlərini saxlayır. Tətbiqin silinməsi tətbiqə aid bütün lokal məlumatları cihazdan ləğv edir.

Şəbəkə və üçüncü tərəflər

Hazırkı build-də uzaq content ünvanı konfiqurasiya edilməyib və şəbəkə sorğusu göndərilmir. Production-da imzalı content yenilənməsi aktivləşdirilərsə, tətbiq yalnız əvvəlcədən icazə verilmiş HTTPS serverindən manifest və dərs paketini tələb edəcək; sorğuya profil adı, şəxsi identifikator və öyrənmə tarixçəsi əlavə edilməyəcək. Şəbəkə serveri standart texniki əlaqə məlumatını, məsələn IP ünvanını, öz təhlükəsizlik jurnallarında emal edə bilər. Tətbiq məlumatı reklam şəbəkələri, data brokerləri və analytics provayderləri ilə paylaşmır.

İcazələr

  • INTERNET — yalnız konfiqurasiya edildikdə imzalı hüquqi content yenilənməsini yoxlamaq üçün;
  • POST_NOTIFICATIONS — istifadəçi bildirişləri aktivləşdirdikdə təkrar xatırlatmaları üçün. İmtina əsas dərs və test funksiyalarını məhdudlaşdırmır.

Təhlükəsizlik

Uzaq content üçün HTTPS host allowlist-i, SHA-256 bütövlük yoxlaması, RSA imzası, schema yoxlaması və tam review coverage preflight-ı tətbiq edilir. Etibarlı public key olmadıqda paket aktivləşmir.

Uşaqlar

Tətbiqin hədəf auditoriyası 16–17 yaşlı və 18 yaşdan yuxarı istifadəçilərdir. Tətbiq 16 yaşdan kiçik uşaqlara yönəlməyib və onlardan şəxsi məlumat toplamaq üçün nəzərdə tutulmayıb.
